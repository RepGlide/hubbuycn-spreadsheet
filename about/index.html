About This Resource

A public sheet / private folio workspace built around a shared HubBuyCN spreadsheet.

What this resource is

This is an independent informational and navigation resource for people who use a HubBuyCN spreadsheet. It helps you keep public research clues separate from private account, order, and payment details.

What this resource is not

This resource is not the official HubBuyCN website, and it is not affiliated with, endorsed by, or operated by HubBuyCN or Google. It is not an order backend, a collaboration database, a cost calculator, or a privacy-insurance promise.

No data collected

This website does not collect or save any user input, and it does not provide upload, login, order tracking, or automatic privacy scanning. There is nothing to sign up for and nothing stored on this site.

How to use it

  1. Open the shared Google Sheet to see the listing references.
  2. Browse the twelve product categories from the home page.
  3. Read the three guides before relying on any listing clue.
  4. Keep public links public and private details private.

Example only — nothing is stored on this site.
